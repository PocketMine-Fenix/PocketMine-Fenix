# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities responsibly using **GitHub private
vulnerability reporting**:

1. Go to the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Provide a description, impact and reproduction steps.

Please do **not** open public issues for security problems.

## What to include

- Version of PocketMine-Fenix affected
- Description of the vulnerability and its impact
- Steps to reproduce or a proof of concept

We will acknowledge reports as soon as possible and coordinate a fix and
disclosure timeline with you.

## Supported versions

Only the latest published release receives security fixes.
