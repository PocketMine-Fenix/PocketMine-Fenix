# 5.46.0

## Added

- Support for Minecraft: Bedrock Edition **1.26.40** (protocol 2168) and current
  **1.26.44** client builds (protocol 2169). Clients on these versions can now join.
- The multi-version range is now **1.20.0 (589) through 1.26.44 (2169)** — 30 client versions.

## Changed

- Protocol and data libraries are now vendored inside this repository under `libs/`,
  making builds fully self-contained.
- Crafting recipes are now sent using UUID-based recipe identifiers and string item descriptors
  for 1.26.40+ clients; older clients keep receiving numeric IDs.
- Updated item upgrade schemas for world data compatibility with recent versions.
