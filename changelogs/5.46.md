# 5.46.0

## Added

- Support for Minecraft: Bedrock Edition **1.26.40** (protocol 2168) and the current
  **1.26.44** client builds (protocol 2169). Clients on these versions can now join.
- The multi-version range is now **1.20.0 (589) through 1.26.44 (2169)** — 30 client versions.

## Changed

- Updated protocol library and Bedrock data to the community-maintained forks now hosted under
  this organisation (`PocketMine-Fenix/BedrockProtocol-NG`, `PocketMine-Fenix/BedrockData-NG`),
  based on the work of NetherGamesMC and kostamax27.
- Crafting recipes are now sent using UUID-based recipe identifiers and string item descriptors
  for 1.26.40+ clients; older clients keep receiving numeric IDs.
- Updated item upgrade schemas (axolotl-pm 1.18.0+bedrock-1.26.40) for world data compatibility.
