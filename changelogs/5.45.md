# 5.45.0

First release of PocketMine-Fenix, the community continuation of PocketMine-MP.

## Highlights

- **Multi-version support**: clients from Minecraft Bedrock **1.20.0 (protocol 589)** through
  **1.26.30 (protocol 1001)** can join the same server simultaneously.
- New configuration option `network.accepted-protocols` in `pocketmine.yml` to restrict which
  client versions may join (defaults to all supported versions).
- Based on PocketMine-MP 5.44.x by the pmmp team, with the multi-version implementation from
  NetherGamesMC's BedrockProtocol/BedrockData and their server fork.
- Updated Composer dependencies; legacy pmmp update-checker disabled by default.
- See [UPDATING.md](/UPDATING.md) for how future Minecraft versions will be supported.

## Notes

- Plugins targeting the PocketMine-MP 5.x API remain compatible.
- Players on older client versions may see newer blocks/items as fallback blocks.
