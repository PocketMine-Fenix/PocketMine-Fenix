# 5.47.0

## Added

- **Java Edition world import (1.18+)**: native paletted chunk reader with blockstate
  translation via PM's global deserializer pipeline. Standard vanilla blocks convert
  correctly; unsupported blocks become air instead of crashing the server.
- `/whatsnew` command (`/changelog` alias): shows release notes from GitHub.
- `updatepm` command: self-update from GitHub Releases (OP/console permission).
- Auto-updater now checks GitHub Releases with periodic re-checks and optional
  background pre-downloading (`auto-updater.check-interval-minutes`,
  `auto-updater.auto-download`).
- OP update notifications on join (`auto-updater.notify-ops-on-join`).
- Console logs player game version, protocol and platform on join.
- Console logs session duration on disconnect.
- `/status` shows online clients grouped by game version plus supported protocol range.
- Server list entry shows `[MV]` tag when multiversion is active.
- Startup banner shows supported client protocol range.

## Changed

- Protocol/data libraries vendored inside this repository under `libs/` as
  first-party `fenix/*` packages -- builds are fully self-contained.
- Updated to Minecraft Bedrock 1.26.44 (protocol 2169) support.
- Vendored pocketmine/nbt fork adds TAG_Long_Array for Java Anvil chunks.
- Cyclic GC runs logged at debug level unless slow (>=10ms), reducing startup spam.
- Encoding buffers reused on packet send hot paths, reducing allocations.
- External crash report submission disabled by default (dumps saved locally).

## Fixed

- Inverted version comparison in update detection.
- Spanish README encoding corruption.
