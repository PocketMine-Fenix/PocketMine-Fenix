# 5.48.0

## Added

- **Java Edition world import (1.18+)**: native paletted chunk reader with
  blockstate translation via PM's global deserializer pipeline. Standard vanilla
  blocks convert correctly; unsupported blocks become air instead of crashing.
- `/whatsnew` command: shows latest release notes from GitHub.
- `updatepm` command: self-update from GitHub Releases (OP/console).
- Auto-updater: periodic re-checks, background pre-downloading, OP notifications on join.
- Console logs player game version, protocol and platform on join.
- Console logs session duration on disconnect.
- `/status` shows online clients grouped by game version plus supported protocols.
- Server list entry shows `[MV]` tag when multiversion is active.

## Changed

- Performance: async-compression enabled by default, compression-level optimized,
  chunk-sending rate doubled, encoding buffers reused on hot paths.
- Cyclic GC runs silenced unless slow (>=50ms) - no more console spam.
- Vendored pocketmine/nbt fork adds TAG_Long_Array for Java Anvil chunks.
- External crash reports disabled by default.

## Fixed

- Inverted version comparison in update detection.
- Spanish README encoding corruption.
